## Problem Understanding & Dataset Analysis

### Forecasting Objective

The primary objective of this project is to develop robust time series forecasting models capable of accurately predicting key environmental variables in Harveston for future time periods. The specific variables targeted for prediction, along with their required units, are: 

* Average Temperature (°C)  
* Radiation (W/m²)  
* Rain Amount (mm)  
* Wind Speed (km/h)  
* Wind Direction (°)

### Expected Outcomes

The expected outcome of this project is a forecasting model that demonstrates high predictive performance based on the evaluation criteria. Success will be measured primarily by minimizing the average **Symmetric Mean Absolute Percentage Error (sMAPE)** across all five target variables on the provided.
